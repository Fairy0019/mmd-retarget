# 路线图

> 每个里程碑都要有**可运行产物 + 可复现验收**，不追完美。

## M0 · 数据层（目标：2 周）

**交付**

- `vmd` 读写器（Shift-JIS、15 字节骨名、30fps、贝塞尔插值、morph）
- `pmx` 读取（骨骼 rest/层级/权重最小集）
- `skeleton_profile.json` 生成
- `canonical_motion.json` 定义与互转
- round-trip 测试

**验收**

- 读入→写出→再读入，未修改骨骼旋转误差 < 0.1°，位移误差 < 0.1mm；
- 中文/日文骨名不丢失；
- 一条命令生成 profile。

## M1 · 身体重定向（目标：3 周）

**交付**

- 比例缩放 + rest/roll 适配
- 脚锁（接触段检测 + 腿 IK + 骨盆补偿）
- 手臂 IK + 极向量 + 间隙约束
- 修正量的膨胀/平均/限速
- 超限帧标记

**验收**

- 30 秒样本：身体穿透 < 2mm，或列入白名单；
- 脚部滑步 < 5mm；
- 相邻帧末端速度无 > 50% 突跳。

## M2 · 检测与标注（目标：2 周）

**交付**

- BVH 相交 + 穿透深度（max / P95）
- 可见性判定（最终机位）
- severity + CSV/JSON 报告 + Blender marker + 缩略图
- 回归 diff

**验收**

- 对验收用例输出可读报告；
- 人工按报告能在 1 小时内定位全部 high 帧。

## M3 · 被动件物理（目标：3 周）

**交付**

- 裙/发/袖骨链 PBD
- 胶囊/球碰撞体，翅膀作为静态碰撞体
- 300 帧试跑脚本 + 全片烘焙

**验收**

- 无抖动/炸开/隧穿；
- 30 秒样本中裙摆、头发无可见穿刺。

## M4 · 集成与发布（目标：1 周）

**交付**

- CLI 子命令完整：`skeleton / inspect / retarget / physics / validate`
- 文档、示例、配置模板
- v0.1.0

**验收**

- 新用户按 README 能在 30 分钟内跑通示例。
