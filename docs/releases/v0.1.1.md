# v0.1.1 · 验收、CI 与 C4-A 结论

这是 v0.1.0 之后的第一个验收版本。重点不是加功能，而是**把 v0.1.1
已经写好的东西跑出数字**，并修掉验收过程中暴露的 bug。

## 亮点

- **头发分组**：side/back 独立参数，`hair-torso` ≥5 mm 从 82 降到 76，
  high 0=0。
- **根运动合并**：`グルーブ` / `全ての親` 位移并入 root；修掉“センター
  没有位移键时直接丢根运动”的 bug（008）。
- **morph 映射**：`--morph-map` 输出目标表情名；验证 blink/smile/angry/wink
  共 2,305 帧，旧名 0。
- **插值保留**：真实 VMD 25,973 个键的 64 字节插值逐字节一致。
- **视觉验收**：`tools/render_acceptance.py` + `--clay`，10 张 640×800，
  0 黑图。
- **物理 CI**：`tools/ci_physics.sh`，900 帧基线，`--max-new 0 --max-worse 0`；
  裙摆回归能被拦住（exit 1）。
- **bug 009**：`physics --skirt` 之前是空开关，已修并加 CLI 测试。

## 已知限制

- 裙摆 C4-A 权重转移无收益，骨链物理会把腿顶穿；默认 `skirt=false`。
- 跨模型只验证了一对（薇斯纳→Lumine）；裙摆 high 仍主要留给 M3。
- 带材质渲染时 `袜` 类材质在 Cycles 下会让腿消失；几何验收请用 `--clay`。
