# 构想

## 1. 问题

MMD 的动作文件（VMD）只包含**骨骼的局部旋转**和**根骨骼位移**。它不包含
骨骼长度、rest 矩阵、roll、质量、碰撞体、关节限位，也不包含"手要到达哪里"的意图。

所以当同一段动作套到另一副骨架上时，会同时出现三种误差：

| 误差 | 表现 |
|---|---|
| **比例** | 臂长/肩宽/裙体积不同，同样的关节角让手落到身体里 |
| **rest / roll** | 骨架静止朝向不同，同样的四元数解出不同的世界朝向（系统性偏内/偏外） |
| **FK 语义** | 动作是纯关节角，没有末端目标；换体型后末端位置必然漂移 |

结果就是：手臂插胸、手穿裙、头发扫过翅膀、裙片穿大腿。

## 2. 为什么现有方案不够

- **VmdSizing**：解决比例与中心/腿 IK，不做碰撞；
- **Auto-Rig Pro / Rokoko**：解决骨架映射，不做碰撞；
- **Unity / UE 重定向**：需要进引擎，且不产出 VMD；
- **手动修**：不可扩展，30fps 下容易在阈值处产生弹跳。

## 3. 原则

1. **传末端轨迹，不传关节角**：先提取"意图"（手腕/脚踝的世界轨迹、接触段），
   再在目标骨架上重新求解。
2. **身体先于衣物**：布料的碰撞体是身体；身体自穿插会让布料求解输入错误。
3. **机器做确定性的事**：检测、投影、烘焙、回归。
   审美与编舞决策交给人。
4. **一切结果烘焙成关键帧**：最终文件不依赖实时模拟，可复现、可回滚。
5. **容差而非零**：几何零相交不现实（皮肤与衣服本来就接触），
   目标是**视觉零穿模**：身体穿透 < 2mm 或白名单；衣物在最终机位不可见。

## 4. 分层

```
┌─────────────────────────────────────────────┐
│ 输入：VMD + 源 skeleton profile + 目标 profile │
└───────────────────┬─────────────────────────┘
                    ▼
        ① 解析 → canonical motion
           （语义关节 / 根轨迹 / 接触段 / morph）
                    ▼
        ② 身体重定向
           比例缩放 → rest/roll 适配 → 脚锁
           → 手臂 IK → 间隙约束 → 时间平滑
                    ▼
        ③ 身体检测（穿透深度 / 可见性 / 标记）
                    ▼
        ④ 被动件物理（裙 / 发 / 袖，骨链 PBD）
                    ▼
        ⑤ 衣物检测 + 回归
                    ▼
        输出：目标模型 VMD + 报告
```

## 5. "完成"的定义

- **身体**：任意帧、任意身体对，穿透深度 < 2mm，或列入"意图接触"白名单；
- **衣物**：在最终机位下不可见穿透；
- **连续性**：相邻帧末端速度无 > 50% 突跳；
- **可复现**：同一输入 + 同一配置，输出一致（模拟结果烘焙后固定）；
- **可回滚**：原始动作与修正动作分离保存。

## 6. 非目标

- 自动编舞 / 自动审美判断；
- 视频渲染与后期；
- 分发受版权保护的模型、动作、音乐；
- 一开始就做"全身主动布娃娃"（实验方向，放最后）。

## 7. 为什么开源

- MMD 生态的痛点具有普遍性，不是单个项目的问题；
- 工具的价值在于**数据格式与验收口径**，越多人用越统一；
- 版权边界清晰：只发布代码，不附带任何素材。
