# 阶段报告 10 · M1 stage 3 承重判断与锚定式平滑

- 日期：2026-10-24
- 范围：`retarget.support_labels`、`smooth_foot_lock`（重写）
- 结论：脚锁现在**同时**满足两个不变量——锁定窗口内漂移 = 0，
  全片最大步长 ≤ 限速。代价是覆盖率从 29.9% 降到 15.1%。

---

## 1. 承重判断

规则（几何启发式）：

1. 当前帧只有一个接触候选 → 该脚承重；
2. 两只脚都接触 → 把骨盆（`下半身`，缺失时退回 `中心`）投影到两脚
   连线上，`t < 0.5` 判左脚，否则右脚；
3. 两脚几乎重合 → 取更低的那只；
4. 没有接触候选 → 不承重。

窗口内承重比例 ≥ 50% 才允许锁；否则记为 `skipped_swing`。

真实动作：

```
chunks           : 493
skipped_swing    : 156
skipped_drift    : 67
skipped_reach    : 53
locked (平滑前)  : 217  （3,372 帧，29.9%）
```

承重判断把 156 个“脚贴地但在迈步”的窗口排除了，锁定窗口从 189 增到
217，覆盖率从 26.8% 升到 29.9%。

## 2. 锚定式平滑

报告 08 的全局平滑会把锁定窗口内部拖走。新算法把锁定帧当**硬约束**：

1. 相邻锁定窗口位置差 ≤ 2 cm → 合并；
2. 差太大 → 放弃后一个窗口，制造空隙；
3. 空隙长度不足以在限速内完成过渡 → 继续放弃相邻窗口，直到够长；
4. 只对未锁定段做线性过渡；
5. 锁定帧一个都不改。

真实动作结果：

```
locked (平滑后)  : 107 窗口 / 1,708 帧 / 15.1%
dropped_smoothing: 58 窗口
ramped_frames    : 8,901
max step         : 2.744 -> 0.126 单位/帧（限速 0.130）
locked drift     : 0.00e+00
整段平均滑步      : 0.1541 -> 0.0298 单位/帧
```

两个不变量同时成立：

- **窗口内漂移 = 0**（脚真的钉住了）；
- **最大步长 ≤ 限速**（没有瞬移）。

## 3. 代价：覆盖率腰斩

为了给过渡留空间，平滑放弃了 58 个窗口，覆盖率从 29.9% 掉到 15.1%。
这是一次明确的取舍：

> 宁可少锁，也不要在窗口边界制造 24 cm/帧 的瞬移。

要提高覆盖率，正确方向不是放宽限速，而是：

1. **骨盆补偿**：53 个 reach 窗口通过移动 root 变得可达；
2. **更长/更聪明的过渡**：在整段未锁定区做贝塞尔过渡，而不是线性；
3. **邻窗合并**：相邻窗口位置差在 2–10 cm 时，用一段短斜坡连接，
   而不是直接放弃；
4. **承重段细分**：把 20 帧窗口切成 10 帧，减少每窗内的漂移差。

## 4. 漏洞与风险

### 4.1 承重判断是几何的，不是力学的

骨盆投影只看位置，不看速度、加速度、脚掌面积、身体倾斜。快速转身时
可能判错支撑脚。误判的后果是锁了摆动脚，表现为“拖脚”。

需要：用骨盆速度/加速度、另一只脚的抬升高度、脚部接触面积做多特征
判断；或者干脆把“哪只脚承重”交给人，在配置里写死区间。

### 4.2 覆盖率只有 15.1%

这是当前最大的质量缺口。M1 的“滑步 < 5 mm”只在锁定窗口内成立；
未锁定段仍然保留源滑步。验收报告必须按“锁定覆盖率”加权，不能只说
“漂移为 0”。

### 4.3 平滑改的是位移，不是修正量

ARCHITECTURE 3.4 建议对**修正量**做膨胀→平均→限速。当前实现是对
最终足 IK 轨迹做锚定过渡，效果等价于对修正量做分段线性，但没有
“膨胀”步骤，单帧尖峰仍可能被漏掉。下一步可以改成修正量空间。

### 4.4 53 个窗口够不到

没有骨盆补偿，这些窗口直接跳过。脚踝目标到髋的距离超过腿长 1.23 倍
时，MMD 的 IK 也会拉伸/抖动；跳过是安全的，但会丢掉一部分本可锁的帧。

### 4.5 仍然只有一个模型

承重判断和平滑参数只在薇斯纳上跑过。换体型、换动作（尤其是慢走、
长时间单脚站立）需要重新标定阈值。

## 5. 测试

`pytest -q`：**69 passed**。新增/调整：

- 承重标签：单脚、双脚投影、骨盆缺失回退 root；
- 锁定窗口在平滑后保持不变（drift = 0）；
- 相邻窗口差太大时放弃后一个；
- 空隙不足时继续放弃，直到最大步长 ≤ 限速；
- 只有单侧锚点时整段过渡，不保留源轨迹内部台阶。

## 6. 下一步

1. 骨盆补偿（53 个 reach 窗口）；
2. 邻窗 2–10 cm 的短斜坡，而不是直接放弃；
3. 手臂 IK + 间隙约束；
4. M2 的 BVH 穿透检测（Blender）。
