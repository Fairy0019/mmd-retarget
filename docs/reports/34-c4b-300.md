## 3. 关键发现：后段漂移，不是参数问题

原始 high 帧与最好候选 high 帧**完全不重叠**：

```
原始 high : 75,105,115,160,195,200,205,255,260,270
候选 high : 161,166,171,181,186,191,196,226,236,241,246,251,256,261,266,291,296
new 17 / fixed 10 / 共同 0
```

第二半段（161–296）布片逐渐褶皱、贴腿，high 是新产生的。调
mass/bending/quality 只能改变褶皱形态，不能阻止漂移；这是**长序列
稳定性**问题。

## 5. 决定

1. **不进入全片**（未通过 300 帧）；
2. 不再调 `--mass/--bending/--quality`——已试 5 组，最好仍 20 high，
   且新 high 与参数无关；
3. 下一步是结构性修复，不是参数：
   - 碰撞代理精度（当前 12% decimate，太粗）；
   - 布片厚度/自碰撞（`use_self_collision=false`）；
   - pin 组（218/3049，腰部可能丢点）；
   - 长序列锚定/分段重置，避免漂移；
4. 仍不回头改骨链参数（报告 17/19 已判死刑）。
