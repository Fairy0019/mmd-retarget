## 1. 头发分组

`physics.py` 新增 `_hair_group(key)`：

- `髮/左`、`髮/右`、`.L/.R` → `side`；
- 其余 → `back`。

`hair_groups` 可为两组分别覆盖参数，默认：

```jsonc
"hair_groups": {
  "side": {"gravity_scale": 0.7, "max_angle_deg": 8.0, "shape_stiffness": 0.08},
  "back": {}
}
```

统计里链名变成 `hair:side:髮/左`，方便按组看 `collision_pushes`。

## 2. 根运动多骨

`canonical.build_canonical` 现在会把 `グルーブ` / `全ての親` 的位移按帧并入
root（近似，假设父空间方向一致），并记录 `root.merged_bones`。

解决报告 19 的「用 `グルーブ` 的动作会丢位移、角色原地踏步」。

## 3. morph 映射

`writer.canonical_to_vmd(..., morph_map=...)`，CLI：

```bash
mmd-retarget retarget motion.json -s src.json -t dst.json -o out.vmd \
  --morph-map morphs.json
# morphs.json: {"まばたき": "blink", "笑い": "smile"}
```

`physics --vmd` 也支持同一参数。

## 4. VMD 插值保留

- canonical 新增 `interpolation`：源 VMD 的非线性 64 字节曲线，按骨名 + 帧号存 hex；
- writer 写回时若帧号匹配则原样使用，否则线性；
- 解决报告 19 的「writer 统一线性，源贝塞尔没保留」（仅对透传键生效，
  重定向产生的新键仍是线性）。

## 5. 视觉验收工具

`tools/render_acceptance.py`：

```bash
blender -b scene.blend --python tools/render_acceptance.py -- \
  --out ../renders/acceptance --frames 0:300:30 --camera 机位_近景 \
  --width 960 --height 1200 --samples 32
```

- 批量渲染抽样帧（Blender 帧号，VMD 0 = Blender 1）；
- 生成 `index.html` 对照表；
- 支持 EEVEE / Cycles。
