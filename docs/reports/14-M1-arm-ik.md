# 阶段报告 14 · M1 stage 4 手臂两骨 IK

- 日期：2026-10-24
- 范围：`retarget.retarget_arms`、`canonical.forward_rotations`
- 结论：手腕目标误差 **均值 3e-8、最大 4e-5 单位**（≈ 0.003 mm）。
  手臂 IK 数值上成立；间隙约束、手部朝向、跨模型验证仍未做。

---

## 1. 算法

对每侧手臂：

1. 用源骨架 FK 取每帧 `S_src`（上臂根）、`E_src`（肘）、`W_src`（腕）；
2. 目标上臂根 `S` 由目标骨架当前躯干姿态决定；
3. 手腕目标：

   ```
   T = S + (W_src - S_src) * scale
   ```

   即“保持源动作里手腕相对肩的位置”，按身高比例缩放；
4. 两骨解析 IK：

   ```
   d = |T - S|，clamp 到 [|L1-L2|, L1+L2]
   a = (L1² - L2² + d²) / 2d
   h = sqrt(L1² - a²)
   E = S + axis*a + perp*h
   ```

   `perp` 取源肘方向在 `S→T` 法平面上的投影，避免肘部翻转；
5. 用最短弧四元数把 rest 上臂/前臂方向转到目标方向；
6. 局部旋转要扣掉父级世界旋转：

   ```
   local_u = from_to(u0, inv(parent_q) * u1)
   world_u = parent_q * local_u
   local_v = from_to(v0, inv(world_u) * v1)
   ```

### 1.1 必须清掉腕捩/手捩

源 VMD 里有 `左腕捩`、`左手捩` 的关键帧。它们让“上臂 → 肘 → 腕”
不再是两段直线，两骨 IK 会把手腕解到错误位置。第一版没清，手腕最大
偏 24 cm；清掉后误差降到 1e-5 量级。

代价是前臂的 roll（拧转）被抹平。M1 后续可以把拧转作为**绕骨轴的
 Twist 分量**叠加回去，而不是让捩骨自由旋转。

## 2. 数值结果

同一模型、scale = 1：

```
sides          : 2
reach clamp    : 10 帧
wrist error    : mean 3.2e-8 / max 4.3e-5 单位
```

4.3e-5 单位 ≈ 0.003 mm。也就是说，在“目标可达到”时，解算器把目标
手腕放到了亚毫米级。

10 帧 reach clamp 是因为源动作把手臂伸到接近完全直；解算器把目标
收短 1e-4 单位，误差仍在 1e-5 量级。

## 3. 对穿模的影响

用 M2 检测对比“未加手臂 IK”和“加手臂 IK”的重定向输出：

| 指标（arm–torso） | 无 IK | 有 IK |
|---|---|---|
| 记录数 | 554 | 551 |
| 最大深度 | 30.99 mm | **29.01 mm** |
| high | 1 | **0** |
| medium | 437 | **424** |

全部位 diff：

```
new 8, fixed 12, worse 107, better 133
```

手臂 IK 只让手臂–躯干略微变好（最大深度 −2 mm，high −1），因为：

- 它只保证**手腕位置**，不保证手/前臂不插进躯干；
- 没有间隙约束，源动作里本来插进躯干的手臂会被原样复现；
- 大部分 diff 来自腿–裙和脊柱链，不是手臂。

## 4. 漏洞与风险

### 4.1 没有间隙约束

M1 的验收要求“手/肘与躯干保持 ≥1.5 cm”。当前 IK 只追手腕位置，
如果源手腕本身在躯干里，目标也会在躯干里。下一步需要：

1. 用 profile 的 19 个胶囊（或 Blender 网格 BVH）做手/前臂–躯干距离；
2. 小于间隙时把 `T` 沿远离躯干的方向推；
3. 推动量 > 8 cm 时标记“编舞不可行”，交人工。

### 4.2 手部朝向没解

`leftHand` 的局部旋转沿用源动作，但它的父级（手捩）被清成 identity，
所以手掌朝向可能和源不一致。需要：

- 把源的腕部世界朝向转成目标局部；
- 或者至少把手捩的 roll 分量加回去。

### 4.3 Twist 被抹平

前臂拧转是舞蹈细节（手心朝向）。当前为了 IK 精度牺牲了它。正确做法
是把 `local_v` 分解成“指向”+“绕轴 roll”，roll 从源捩骨继承。

### 4.4 跨模型未验证

只有一个模型，scale 逻辑只用合成测试覆盖。不同肩宽/臂长比例下，
pole 方向和手腕目标是否合理，需要第二副 PMX。

### 4.5 肘部极向量

极向量取源肘方向。如果源肘几乎在 `S→T` 线上（手臂完全伸直），
`perp` 退化，会落到一个固定垂直方向，肘部可能突然翻转。当前 10 帧
reach clamp 就是这种临界情况。需要加“极向量时间平滑”。

## 5. 测试

`pytest -q`：**78 passed**。新增：

- `_qfrom_to` 的 90°/180° 旋转；
- 合成两骨手臂：源上臂 90°，目标手腕落到 (0,2,0)（1e-3 容差）。

## 6. 下一步

1. 间隙约束（胶囊或 BVH）；
2. 手部朝向 + twist roll 恢复；
3. 极向量平滑；
4. 第二副 PMX 跨模型验收；
5. 骨盆补偿（M1 遗留的 53 个 reach 窗口）。
