# 任务 1.2 · 根运动合并验收

- 日期：2026-10-25
- 计划：`docs/plans/2026-10-26-server-next.md` 任务 1.2
- 对象：恋爱循环前 300 帧 + 人为叠加 `グルーブ` 位移（+2 单位）
- 结论：**通过**。位移不丢；脚锁覆盖率基本不变，滑步略降。
- 同时修掉一个真 bug：纯 `グルーブ` 动作会丢根运动（bug 008）。

---

## 1. 方法

真实动作只有 `センター` 位移，所以合成两版 300 帧样本：

| 样本 | 内容 |
|---|---|
| `orig` | 真实前 300 帧，原样 |
| `merged` | 同上，额外给 `グルーブ` 加 `z: 0 → 2` 的位移键（每 10 帧） |

分别 `build_canonical` → `retarget`（同模型）→ 比较：

- `root.merged_bones`；
- 末帧 root 位移差；
- 脚锁窗口/帧数/覆盖率；
- 平均滑步；
- 骨盆补偿次数。

## 2. 结果

### 2.1 根运动

| 样本 | merged_bones | root 末帧 z |
|---|---|---:|
| orig | — | -0.3925 |
| merged | `["グルーブ"]` | **1.6075** |

差值 **+2.0000**，与人为叠加一致，位移没有丢。

### 2.2 脚锁

| 指标 | orig | merged |
|---|---:|---:|
| 锁定窗口 | 4 | 4 |
| 锁定帧 | 80 | 80 |
| 覆盖率 | 13.38% | 13.33% |
| 平均滑步 | 0.0423 | **0.0405** |
| 骨盆补偿 | 0 | 1 |

覆盖率 -0.05 个百分点（80 帧样本，属于噪声级），滑步没有反弹，反而略低。
骨盆补偿多 1 次，说明 root 前移后有一个窗口需要轻微补髋。

## 3. 修复的 bug

纯 `グルーブ`（センター 没有位移键）时，`_merge_extra_roots` 旧实现
在 `root.pos` 为空时直接返回，导致根运动完全丢失。

修复：没有基础位移时用全零序列作基底，再叠加 `グルーブ/全ての親`。

复盘见 [`docs/bugs/008-root-merge-requires-center.md`](../bugs/008-root-merge-requires-center.md)；
新增回归测试：

```
tests/test_canonical.py::test_root_merges_groove_without_center_translation
```

## 4. 边界

- 只合并**位移**；`グルーブ` 的旋转仍留在 `extra`，因为 canonical 只有一个
  root 旋转通道；
- 合并假设 `センター` / `グルーブ` / `全ての親` 的父空间方向一致（MMD 常见，
  但不是数学严格）；
- 只测了 `グルーブ`；`全ての親` 走同一代码路径，没有单独造样本；
- 300 帧样本，不是全片；全片结论需要任务 3 的 CI 回归。

## 5. 结论

任务 1.2 **通过**，并修复 bug 008。下一步任务 1.3（morph 映射）。
