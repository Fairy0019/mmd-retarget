# 阶段报告 07 · M1 stage 2 脊柱链拆分与回放验证

- 日期：2026-10-23
- 范围：`retarget.retarget_rotations`、`retarget_motion`、Blender 回放对比
- 结论：源 `上半身` 的旋转已能均分到目标
  `上半身/上半身1/上半身2`；把重定向结果重新导入 Blender 后，上半身
  位置中位偏差 **7.2 mm**、最大 2.8 cm。链拆分成立，但还没到 1 cm 验收线。

---

## 1. 为什么可以直接复制局部旋转

M0 报告 05 已经用 Blender 对拍证明：非 IK 骨（脊柱、手臂、头）的
`parent_world * local` 复合与 Blender 的 pose matrix 中位误差 **1.2 mm**。
也就是说，MMD 的 VMD 局部四元数已经是“相对 rest 的旋转”，同语义骨
直接复制不会引入 rest/roll 系统误差。

真正的差异来自**链长**：

```
源:   腰 → 上半身 ─────────────→ 首
目标: 腰 → 上半身 → 上半身1 → 上半身2 → 首
```

源只有一个 `上半身` 关键帧，目标有三段。直接复制会让胸口只在一个关节
处突然弯折，手臂根部位置偏移。M1 stage 2 处理这件事。

## 2. 算法：等分旋转

对目标脊柱链 `[spine, spine1, spine2, spine3]`：

1. 找到源里**有键**的链成员；
2. 如果它后面跟着目标有、但源没有的链成员，就把这段旋转按
   `n = 1 + 缺失数量` 等分；
3. 每一段写入 `slerp(identity, q, 1/n)`。

同一旋转轴时，`q^(1/n)` 连乘严格等于 `q`，末端世界朝向不变；混合轴时
是近似。源样本的脊柱基本是单轴弯曲，所以近似误差很小。

例：源 `上半身` 30° 绕 Z，目标三段 → 每段 10°，复合回 30°。

## 3. 真实动作回放验证

流程：

```bash
# 1) 生成 canonical
python -m mmd_retarget.cli inspect 恋爱循环.vmd -p profile.json -o motion.json
# 2) 重定向（同模型，scale=1）
python -m mmd_retarget.cli retarget motion.json -s profile.json -t profile.json -o out.vmd
# 3) 用 Blender + MMD Tools 分别回放源 / 重定向结果，采 17 帧
blender -b --python tools/blender_dump_pose.py -- 薇斯纳.pmx out.vmd dump_out.json
```

结果（源 vs 重定向后的世界位置，PMX 单位）：

| 部位 | 中位偏差 | 最大偏差 | 说明 |
|---|---|---|---|
| 上半身 / 上半身2 / 首 / 頭 | 0.083 | 0.323 | 链拆分 + 线性插值 |
| 肩 / 腕 / ひじ / 手首 | 0.083 | 0.324 | 继承上半身 |
| センター / 大腿 | 0.013 | 0.295 | 未改动 |
| 膝 | 0.024–0.029 | 0.99 | IK 差异 |
| 脚踝 / 脚趾 | **0.000** | 0.45–1.24 | 锁定的窗口被改到段均值 |

换算：0.083 单位 ≈ **7.2 mm**，0.323 ≈ 2.8 cm，1.236 ≈ 10.8 cm。

关键结论：

- 上半身链条的**末端朝向保持住了**，偏差在毫米级；
- 脚踝在采样点上中位偏差为 0，说明锁定窗口的常量键被正确回放；
- 脚踝最大 10.8 cm 出现在“被锁到窗口均值”的帧，这是**有意**的滑步
  修正，不是误差；但没有平滑，视觉上可能突兀。

## 5. 漏洞与风险

### 5.1 等分旋转是近似

对混合轴旋转，`slerp(I,q,1/3)^3 ≠ q`。当前样本误差 2.8 cm 的上限里，
一部分来自这里，一部分来自线性插值。更严格的做法是按**世界旋转增量**
在目标链上做球面分解（需要每帧目标父级世界旋转），或者在 Blender 里
直接约束。M1 stage 3 若要做手臂 IK，顺手把脊柱改成世界增量法。

### 5.2 脚锁让脚“跳”

分窗锁定的位置在窗口边界不连续，Blender 回放里脚踝最大变化 10.8 cm。
这是 stage 1 已知问题，stage 3 的时间平滑要处理：
膨胀 → 平均 → 限速，作用在**锁定位置序列**上。

### 5.3 线性插值

writer 统一写线性插值；源 VMD 的贝塞尔曲线没有保留。上半身 7.2 mm 的
中位偏差很可能主要来自这里（采样帧大多不是关键帧）。若要压到 1 cm
以内，需要把源曲线的 4 个控制点存进 canonical。

### 5.4 同模型验证的局限

这次仍是“薇斯纳 → 薇斯纳”。链拆分逻辑与比例无关，但**跨体型**的
手臂末端误差还没测。没有第二副人类模型，这是硬缺口。

### 5.5 物理骨仍然不动

63 根目标没有的骨被丢弃；目标自己的头发/裙/袖保持 rest。回放里衣服
是“冻住”的，等 M3。

### 5.6 旋转只覆盖有键的语义

源动作没有 `上半身1/2` 的键，链拆分靠 `spine` 推导；如果源有
`上半身1` 但目标没有对应语义，会被丢弃（当前 map 覆盖了目标全部脊柱段，
所以没触发）。
