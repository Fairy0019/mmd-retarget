# 任务 1.5 · 视觉验收工具

- 日期：2026-10-25
- 计划：`docs/plans/2026-10-26-server-next.md` 任务 1.5
- 场景：薇斯纳 + 恋爱循环，相机 `机位_近景`
- 结论：**通过**。10 张 640×800 图，构图完整、曝光正常、无黑图。

---

## 1. 场景

- Blender 5.2.2 + MMD Tools；
- **先 `frame_set(0)` 再 `import_vmd`**（计划里的注意事项）；
- 相机 `机位_近景`：50 mm，正面偏右，距离约 2.35×身高；
- 一盏主 Sun + 一盏补 Sun + 深灰世界。

## 2. 渲染

```bash
blender -b --python tools/render_acceptance.py -- \
  --blend scene_accept.blend --out acc_final \
  --frames 0:270:30 --camera 机位_近景 \
  --width 640 --height 800 --samples 16 \
  --engine CYCLES --clay
```

结果：

| 项 | 数值 |
|---|---|
| 帧 | 0, 30, …, 270（10 张） |
| 分辨率 | 640×800 |
| 引擎/采样 | Cycles CPU / 16 |
| 耗时 | **1 min 37 s** |
| 输出 | 10 PNG + `index.html` |
| 黑图 | 0 |

抽看 frame 0 / 240：全身完整，翅膀、裙摆、腿、靴子都在画面内；
曝光正常，没有裁切。

## 3. 发现：带材质渲染时腿部“消失”

第一版带材质渲染（无 `--clay`）时，裙摆以下是空的，只有靴子悬空。
用 **material override（clay）** 后腿和靴子完整出现，说明：

- 几何/骨骼没问题；
- 是 `袜/袜s/袜s2` 材质的透明/混合节点在 Cycles 下把腿渲染没了；
- 强制 Alpha=1 也没有解决，说明不是简单的 Principled Alpha，而是
  MMD Tools 的透明节点组/贴图混合。

因此给 `render_acceptance.py` 增加 `--clay`：

- 几何验收（穿模、轮廓、构图）**必须用 clay**；
- 材质/贴图验收要另修材质，不能拿 clay 图当最终效果。

暴力把材质改成 OPAQUE 也没用，说明不能靠“一键去透明”绕过；这是
MMD 材质导入的一个真实缺口，后续应记录/修复。

## 4. 边界

- clay 图不能判断纹理、透明、发光；
- 单机位；转身/背面穿模需要再加机位；
- 10 帧只覆盖前 300 帧（约 10 秒），全片验收要 `0:5640:300` 或分段。

## 5. 结论

任务 1.5 **通过**。视觉验收工具可用，推荐命令里加 `--clay`。
