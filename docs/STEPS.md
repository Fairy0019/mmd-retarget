# 开发步骤（初步拆解）

> 这是把 [PLAN.md](PLAN.md) 的里程碑拆成**可执行的步骤**。粒度以“一个人一周内
> 能交付并验收”为准。顺序可以调整，但依赖关系不能反。

## 0. 依赖关系

```
① VMD parser ──┐
                ├──→ ④ canonical motion ──→ ⑤ retarget ──→ ⑨ writer
② PMX parser ──┤                              │
                └──→ ③ skeleton profile ──────┘
                                               │
                                               ├──→ ⑩ validation
                                               └──→ ⑪ passive physics
```

**最小可跑通路径**：①→②→③→④→⑨（round-trip，不需要 Blender）。

## 2. 每步的关键点与验收

### ① VMD parser

- **输入**：`.vmd`
- **输出**：`canonical` 原始结构（骨名、帧、位移、四元数、插值、morph）
- **坑**：Shift-JIS 15 字节定长、尾部 `\0`、30fps、插值参数 64 字节、相机/灯光轨
- **验收**：
  - 读入→写出→再读入，骨骼旋转误差 < 0.1°，位移 < 0.1mm；
  - 中文/日文骨名不丢失；
  - 5640 帧 × 140 骨在 10 秒内完成解析。

### ② PMX parser

- 只取：骨骼（名、父、rest head/tail、layer）、顶点权重、材质名、morph 名
- **不取**：贴图、刚体、物理（后续需要再说）
- **验收**：骨骼数/层级与 PMXEditor 一致；权重索引不越界。

### ③ skeleton profile

- 生成 `map`（语义名 → 目标骨名）、`rest`、`limits`、`colliders`
- **坑**：`.L/.R` 后缀、日文名、MMD 标准名混用
- **验收**：手工抽查 10 根骨；`map` 覆盖率 > 95%。

### ④ canonical motion

- 语义关节化；提取根轨迹、接触段（脚）、morph
- **验收**：可视化对比源动作（曲线重合）；接触段无抖动。

### ⑤ 比例 + rest/roll

- 世界空间旋转增量法（见 ARCHITECTURE 3.1）
- **验收**：静止 T/A pose 下，目标末端位置与“按比例缩放后的期望位置”误差 < 1cm。

### ⑥ 脚锁

- 接触检测：高度 + 速度阈值；锁定世界位置；腿 IK；骨盆补偿
- **验收**：接触段滑步 < 5mm；膝盖不反关节。

### ⑦ 手臂 IK + 间隙

- 源手腕轨迹为目标；极向量取源肘；胶囊间隙 1.5cm
- **验收**：30 秒样本身体穿透 < 2mm 或白名单；肘部无翻转。

### ⑧ 时间平滑

- 对**修正量**膨胀 → 平均 → 限速
- **验收**：相邻帧末端速度无 > 50% 突跳（以 v2 数据为基线）。

### ⑨ VMD writer

- 写回目标骨骼名（日文标准名，CP932）
- **验收**：MMD/MMD Tools 能直接导入；时长/帧率/表情正确。

### ⑩ 检测与报告

- BVH 相交 + 深度 + 可见性 + severity + 回归 diff
- **验收**：报告可定位 high 帧；人工 1 小时内能处理完。

### ⑪ 被动件物理

- PBD 骨链，胶囊碰撞，单帧最大 5–12°
- **验收**：300 帧试跑稳定；全片无可见穿刺。

### ⑫ 集成

- `skeleton / inspect / retarget / physics / validate` 五个子命令
- **验收**：新用户 30 分钟跑通示例。
